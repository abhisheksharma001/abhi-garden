# Abhishek's Garden 🌱

A minimal personal digital garden — inspired by [tarat.space](https://www.tarat.space/).

Hand-rolled HTML + CSS. No build step, no JavaScript, no tracking.

## Pages

- `/` — home
- `/startups` — building stuff, one stupid idea at a time
- `/writings` — blogs, shower thoughts, rants
- `/projects` — experiments and builds
- `/library` — books and reads
- `/timeline` — progress and milestones

## Local preview

```sh
python3 -m http.server 8741
# open http://localhost:8741/
```
